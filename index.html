Method & limits

How to read this

Windows are grouped by five-hour reset time; only those reaching 80% are shown. Full-window values divide recorded tokens and dollars by the reported usage fraction. That assumes linear use beyond the last reading. Dollars use dated standard API token prices, not subscription charges.

More on sources and uncertainty

Reset times within 120 seconds are merged. Native Codex token events are counted through the last limit reading; other clients may be absent. Early GPT-5.5 cache pricing is inferred, and four July windows have unpriced auto-review tokens. The data excludes prompts and transcripts. OpenAI says published credit prices alone do not determine included subscription usage.
