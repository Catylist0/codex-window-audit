Local Codex logs report how much of each five-hour allowance was used. We paired those readings with token counts and dated standard API prices to compare the dollar-equivalent usage across windows and models.

The finding

A visible shift, with a model change at the same time.

In the high-coverage subset (peak at least 85%, minimum recorded usage at most 5%), the median standard API equivalent falls from about $15.0 to $11.2 per 100%—roughly 25%. Tokens per 100% fall from about 25.0 million to 5.6 million. This is an association, not proof of a hidden limit reduction.

All three Astra windows stopped below 100%, so their full-window dollar amounts are extrapolations. The model switch, possible model-specific allowance weighting, concurrent usage outside native logs, and a small Astra sample prevent a clean before/after causal test.

Observed

The high-coverage Sol and Astra groups do not overlap in API-equivalent dollars per 100% in this sample. Weekly usage remained below 90%, making a weekly cap an unlikely explanation for these particular windows.

Unresolved

Model and date change together. OpenAI says allowance use varies with model, context, reasoning, tools, caching, and speed. Published credit rates are proportional to standard API prices for these two models, but credit prices alone do not determine included usage.

Next check

Collect more Astra windows, especially observed 100% windows, while keeping plan, speed, and client constant. A same-model comparison across a suspected change date would be stronger evidence of a quota change.

Method & limits

What this can—and cannot—show

Window identity

Codex token-count events carry a primary five-hour usage percentage and reset time. Readings with reset times within 120 seconds were treated as one window; this merges an overlapping July 2 split. A window qualifies if its highest recorded percentage is at least 80%.

Cost calculation

For each qualifying window, local Codex token events between reset minus five hours and its last reading were priced by model and token type. Reported USD sums fresh input, cached input, cache writes, and output at standard short-context API rates. Projected full-window USD divides by the reported usage fraction, assuming a linear relationship over the unobserved remainder.

Not a billing record

These are standard API-equivalent estimates for subscription activity, not charges paid. The logs omit activity from clients that do not write native Codex sessions. Hosted tools, long-context and fast-mode premiums, and any undocumented allowance weighting are not measured. OpenAI says credit prices alone do not determine included subscription usage.

Historical prices

Recent rates come from the widget’s dated price ledger. Earlier GPT-5.5 cached-input prices are inferred from the currently published rate, alongside its published launch input/output rates. Four July windows include unpriced codex-auto-review usage; their displayed dollars are lower bounds.
